অনুশীলনী ৫.১

গণিত – পৃষ্ঠা ৭৫–৭৬ | বিস্তারিত ধাপে ধাপে সমাধান

সূত্রের সাহায্যে বর্গ নির্ণয় করো (১–১৬)

সূত্র: (a + b)² = a² + 2ab + b²  |  (a − b)² = a² − 2ab + b²  |  (a + b + c)² = a² + b² + c² + 2ab + 2bc + 2ca

১ a + 5

সমাধান: (a + 5)²
= a² + 2·a·5 + 5²  [(a+b)² সূত্র]
= a² + 10a + 25
উত্তর: a² + 10a + 25

২ 5x − 7

সমাধান: (5x − 7)²
= (5x)² − 2·5x·7 + 7²  [(a−b)² সূত্র]
= 25x² − 70x + 49
উত্তর: 25x² − 70x + 49

৩ 3a − 11xy

সমাধান: (3a − 11xy)²
= (3a)² − 2·3a·11xy + (11xy)²
= 9a² − 66axy + 121x²y²
উত্তর: 9a² − 66axy + 121x²y²

৪ 5a² + 9m²

সমাধান: (5a² + 9m²)²
= (5a²)² + 2·5a²·9m² + (9m²)²
= 25a⁴ + 90a²m² + 81m⁴
উত্তর: 25a⁴ + 90a²m² + 81m⁴

৫ 55

সমাধান: 55² = (50 + 5)²
= 50² + 2·50·5 + 5²
= 2500 + 500 + 25
= 3025
উত্তর: 3025

৬ 990

সমাধান: 990² = (1000 − 10)²
= 1000² − 2·1000·10 + 10²
= 1000000 − 20000 + 100
= 980100
উত্তর: 980100

৭ xy − 6y

সমাধান: (xy − 6y)²
= (xy)² − 2·xy·6y + (6y)²
= x²y² − 12xy² + 36y²
উত্তর: x²y² − 12xy² + 36y²

৮ ax − by

সমাধান: (ax − by)²
= (ax)² − 2·ax·by + (by)²
= a²x² − 2abxy + b²y²
উত্তর: a²x² − 2abxy + b²y²

৯ 97

সমাধান: 97² = (100 − 3)²
= 100² − 2·100·3 + 3²
= 10000 − 600 + 9
= 9409
উত্তর: 9409

১০ 2x + y − z

সমাধান: (2x + y − z)²
= (2x)² + y² + (−z)² + 2·2x·y + 2·y·(−z) + 2·(−z)·2x  [(a+b+c)² সূত্র]
= 4x² + y² + z² + 4xy − 2yz − 4zx
উত্তর: 4x² + y² + z² + 4xy − 2yz − 4zx

১১ 2a − b + 3c

সমাধান: (2a − b + 3c)²
= (2a)² + (−b)² + (3c)² + 2·2a·(−b) + 2·(−b)·3c + 2·3c·2a
= 4a² + b² + 9c² − 4ab − 6bc + 12ca
উত্তর: 4a² + b² + 9c² − 4ab − 6bc + 12ca

১২ x² + y² − z²

সমাধান: (x² + y² − z²)²
= (x²)² + (y²)² + (−z²)² + 2·x²·y² + 2·y²·(−z²) + 2·(−z²)·x²
= x⁴ + y⁴ + z⁴ + 2x²y² − 2y²z² − 2z²x²
উত্তর: x⁴ + y⁴ + z⁴ + 2x²y² − 2y²z² − 2z²x²

১৩ a − 2b − c

সমাধান: (a − 2b − c)²
= a² + (−2b)² + (−c)² + 2·a·(−2b) + 2·(−2b)·(−c) + 2·(−c)·a
= a² + 4b² + c² − 4ab + 4bc − 2ca
উত্তর: a² + 4b² + c² − 4ab + 4bc − 2ca

১৪ 3x − 2y + z

সমাধান: (3x − 2y + z)²
= (3x)² + (−2y)² + z² + 2·3x·(−2y) + 2·(−2y)·z + 2·z·3x
= 9x² + 4y² + z² − 12xy − 4yz + 6zx
উত্তর: 9x² + 4y² + z² − 12xy − 4yz + 6zx

১৫ bc + ca + ab

সমাধান: (bc + ca + ab)²
= (bc)² + (ca)² + (ab)² + 2·bc·ca + 2·ca·ab + 2·ab·bc
= b²c² + c²a² + a²b² + 2abc² + 2a²bc + 2ab²c
উত্তর: a²b² + b²c² + c²a² + 2abc(a + b + c)

১৬ 2a² + 2b − c²

সমাধান: (2a² + 2b − c²)²
= (2a²)² + (2b)² + (−c²)² + 2·2a²·2b + 2·2b·(−c²) + 2·(−c²)·2a²
= 4a⁴ + 4b² + c⁴ + 8a²b − 4bc² − 4a²c²
উত্তর: 4a⁴ + 4b² + c⁴ + 8a²b − 4a²c² − 4bc²

সরল করো (১৭–২৪)

সূত্র: A² − 2AB + B² = (A − B)²  |  A² + 2AB + B² = (A + B)²

১৭ (2a + 1)² − 4a(2a + 1) + 4a²

সমাধান: ধরি, A = 2a + 1 এবং B = 2a। তাহলে 4a(2a+1) = 2·(2a+1)·2a = 2AB এবং 4a² = (2a)² = B²
প্রদত্ত রাশি = A² − 2AB + B² = (A − B)²
= {(2a + 1) − 2a}² = 1² = 1
উত্তর: 1

১৮ (5a + 3b)² + 2(5a + 3b)(4a − 3b) + (4a − 3b)²

সমাধান: ধরি, A = 5a + 3b, B = 4a − 3b
প্রদত্ত রাশি = A² + 2AB + B² = (A + B)²
= {(5a + 3b) + (4a − 3b)}² = (9a)² = 81a²
উত্তর: 81a²

১৯ (7a + b)² − 2(7a + b)(7a − b) + (7a − b)²

সমাধান: ধরি, A = 7a + b, B = 7a − b
প্রদত্ত রাশি = A² − 2AB + B² = (A − B)²
= {(7a + b) − (7a − b)}² = (7a + b − 7a + b)² = (2b)² = 4b²
উত্তর: 4b²

২০ (2x + 3y)² + 2(2x + 3y)(2x − 3y) + (2x − 3y)²

সমাধান: ধরি, A = 2x + 3y, B = 2x − 3y
প্রদত্ত রাশি = (A + B)² = {(2x + 3y) + (2x − 3y)}²
= (4x)² = 16x²
উত্তর: 16x²

২১ (5x − 2)² + (5x + 7)² − 2(5x − 2)(5x + 7)

সমাধান: ধরি, A = 5x − 2, B = 5x + 7
প্রদত্ত রাশি = A² + B² − 2AB = (A − B)²
= {(5x − 2) − (5x + 7)}² = (5x − 2 − 5x − 7)² = (−9)² = 81
উত্তর: 81

২২ (3ab − cd)² + 9(cd − ab)² + 6(3ab − cd)(cd − ab)

সমাধান: ধরি, A = 3ab − cd, B = 3(cd − ab)
তাহলে B² = 9(cd − ab)² এবং 2AB = 6(3ab − cd)(cd − ab)
প্রদত্ত রাশি = A² + B² + 2AB = (A + B)²
= {(3ab − cd) + 3(cd − ab)}² = (3ab − cd + 3cd − 3ab)² = (2cd)² = 4c²d²
উত্তর: 4c²d²

২৩ (2x + 5y + 3z)² + (5y + 3z − x)² − 2(5y + 3z − x)(2x + 5y + 3z)

সমাধান: ধরি, A = 2x + 5y + 3z, B = 5y + 3z − x
প্রদত্ত রাশি = A² + B² − 2AB = (A − B)²
= {(2x + 5y + 3z) − (5y + 3z − x)}² = (2x + 5y + 3z − 5y − 3z + x)² = (3x)² = 9x²
উত্তর: 9x²

২৪ (2a − 3b + 4c)² + (2a + 3b − 4c)² + 2(2a − 3b + 4c)(2a + 3b − 4c)

সমাধান: ধরি, A = 2a − 3b + 4c, B = 2a + 3b − 4c
প্রদত্ত রাশি = A² + B² + 2AB = (A + B)²
= {(2a − 3b + 4c) + (2a + 3b − 4c)}² = (4a)² = 16a²
উত্তর: 16a²

মান নির্ণয় করো (২৫–২৮)

২৫ 25x² + 36y² − 60xy, যখন x = −4, y = −5

সমাধান: 25x² + 36y² − 60xy = (5x)² − 2·5x·6y + (6y)² = (5x − 6y)²
x = −4, y = −5 বসিয়ে পাই, (5·(−4) − 6·(−5))²
= (−20 + 30)² = 10² = 100
উত্তর: 100

২৬ 16a² − 24ab + 9b², যখন a = 7, b = 6

সমাধান: 16a² − 24ab + 9b² = (4a)² − 2·4a·3b + (3b)² = (4a − 3b)²
a = 7, b = 6 বসিয়ে পাই, (4·7 − 3·6)² = (28 − 18)² = 10² = 100
উত্তর: 100

২৭ 9x² + 30x + 25, যখন x = −2

সমাধান: 9x² + 30x + 25 = (3x)² + 2·3x·5 + 5² = (3x + 5)²
x = −2 বসিয়ে পাই, (3·(−2) + 5)² = (−6 + 5)² = (−1)² = 1
উত্তর: 1

২৮ 81a² + 18ac + c², যখন a = 7, c = −67

সমাধান: 81a² + 18ac + c² = (9a)² + 2·9a·c + c² = (9a + c)²
a = 7, c = −67 বসিয়ে পাই, (9·7 + (−67))² = (63 − 67)² = (−4)² = 16
উত্তর: 16

প্রমাণ ও মান নির্ণয় (২৯–৩৪)

২৯ a − b = 7 এবং ab = 3 হলে, দেখাও যে, (a + b)² = 61

সমাধান: আমরা জানি, (a + b)² = (a − b)² + 4ab
= 7² + 4·3 = 49 + 12 = 61
(a + b)² = 61 (দেখানো হলো)

৩০ a + b = 5 এবং ab = 12 হলে, দেখাও যে, a² + b² = 1

সমাধান: আমরা জানি, a² + b² = (a + b)² − 2ab
= 5² − 2·12 = 25 − 24 = 1
a² + b² = 1 (দেখানো হলো)

৩১ x + 1x = 5 হলে, প্রমাণ কর যে, (x² − 1x²)² = 525

সমাধান: দেওয়া আছে, x + 1/x = 5
x² + 1/x² = (x + 1/x)² − 2·x·(1/x) = 5² − 2 = 23
এখন, (x² − 1/x²)² = (x² + 1/x²)² − 4·x²·(1/x²)
= 23² − 4 = 529 − 4 = 525
(x² − 1/x²)² = 525 (প্রমাণিত)

৩২ a + b = 8 এবং a − b = 4 হলে, ab = কত?

সমাধান: আমরা জানি, (a + b)² − (a − b)² = 4ab
বা, 8² − 4² = 4ab
বা, 64 − 16 = 4ab
বা, 4ab = 48
∴ ab = 48 ÷ 4 = 12
উত্তর: ab = 12

৩৩ x + y = 7 এবং xy = 10 হলে, x² + y² + 5xy এর মান কত?

সমাধান: x² + y² = (x + y)² − 2xy = 7² − 2·10 = 49 − 20 = 29
∴ x² + y² + 5xy = 29 + 5·10 = 29 + 50 = 79
উত্তর: 79

৩৪ m + 1m = 2 হলে, দেখাও যে, m⁴ + 1m⁴ = 2

সমাধান: দেওয়া আছে, m + 1/m = 2
m² + 1/m² = (m + 1/m)² − 2 = 2² − 2 = 2
আবার, m⁴ + 1/m⁴ = (m² + 1/m²)² − 2·m²·(1/m²)
= 2² − 2 = 4 − 2 = 2
m⁴ + 1/m⁴ = 2 (দেখানো হলো)
