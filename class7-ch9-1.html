NCTB গণিত · জ্যামিতি · ধাপে ধাপে সমাধান ও প্রমাণ

১চিত্রে ∠ABD, ∠CBD এবং ∠BCD-এর মান নির্ণয় করো।

চিত্রে ∠ABC=90°, ∠BAC=48° এবং BD ⟂ AC।

প্রথমে △ABC-এর তিন কোণের সমষ্টি ব্যবহার করি। ত্রিভুজের তিনটি অন্তঃকোণের সমষ্টি 180°।
∠BAC + ∠ABC + ∠ACB = 180°
প্রদত্ত মান বসালে, 48° + 90° + ∠ACB = 180°।
∠ACB = 180° − 138° = 42°
BD ⟂ AC বলে ∠ADB=90°। আবার D বিন্দু AC-এর ওপর, তাই ∠BAD=∠BAC=48°। △ABD-এ,
∠BAD + ∠ADB + ∠ABD = 180°
48° + 90° + ∠ABD = 180°
∠ABD = 180° − 138° = 42°
BD রেখাটি সমকোণ ∠ABC-কে দুই ভাগে বিভক্ত করেছে। তাই, ∠ABD + ∠CBD = ∠ABC।
42° + ∠CBD = 90° ⇒ ∠CBD = 48°
A,D,C একই সরলরেখায়, তাই ∠BCD=∠BCA=42°।
উত্তর: ∠ABD=42°, ∠CBD=48° এবং ∠BCD=42°।

২একটি সমদ্বিবাহু ত্রিভুজের শীর্ষবিন্দুতে অবস্থিত কোণের মান 50°। অবশিষ্ট কোণ দুটির মান নির্ণয় করো।

সমদ্বিবাহু ত্রিভুজে ভূমিসংলগ্ন কোণ দুটি সমান।

ধরি, অবশিষ্ট দুই সমান কোণের প্রত্যেকটি x°। ত্রিভুজের তিন কোণের সমষ্টি 180°।
x° + x° + 50° = 180°
2x° = 180° − 50° = 130°
x = 130° ÷ 2 = 65°
উত্তর: অবশিষ্ট কোণ দুটি প্রত্যেকটি 65°।

৩প্রমাণ করো যে, চতুর্ভুজের চারটি কোণের সমষ্টি চার সমকোণের সমান।

কর্ণ AC আঁকলে চতুর্ভুজটি দুটি ত্রিভুজে বিভক্ত হয়।

প্রমাণ: ধরা যাক, ABCD একটি চতুর্ভুজ। A ও C শীর্ষবিন্দু যোগ করে কর্ণ AC আঁকি। ফলে চতুর্ভুজটি △ABC ও △ACD — দুটি ত্রিভুজে বিভক্ত হয়।
△ABC-এর কোণগুলোর সমষ্টি থেকে পাই,
∠BAC + ∠ABC + ∠BCA = 180° … (১)
একইভাবে △ACD-এর জন্য,
∠CAD + ∠ACD + ∠CDA = 180° … (২)
(১) ও (২) যোগ করলে,
∠BAC + ∠CAD + ∠ABC + ∠BCA + ∠ACD + ∠CDA = 360°
∠BAC + ∠CAD = ∠DAB এবং ∠BCA + ∠ACD = ∠BCD। সুতরাং,
∠DAB + ∠ABC + ∠BCD + ∠CDA = 360°
এক সমকোণ 90°; চার সমকোণ 4 × 90° = 360°।
অতএব, চতুর্ভুজের চারটি কোণের সমষ্টি চার সমকোণ (অর্থাৎ 360°)। প্রমাণিত।

৪△ABC-এর AC ⟂ BC; E, AC-এর বর্ধিতাংশের ওপর যেকোনো বিন্দু এবং ED ⟂ AB। ED এবং BC পরস্পরকে O বিন্দুতে ছেদ করে। প্রমাণ করো যে, ∠CEO = ∠DBO।

প্রদত্ত: AC ⟂ BC, ED ⟂ AB; O হলো ED ও BC-এর ছেদবিন্দু।

প্রমাণ: প্রদত্ত, AC ⟂ BC এবং ED ⟂ AB। তাই CE ⟂ CO এবং DE ⟂ DB।
অতএব, △CEO ও △DBO-তে,
∠ECO = 90° এবং ∠BDO = 90°
ত্রিভুজের তিন কোণের সমষ্টি 180° হওয়ায়, সমকোণী △CEO-তে
∠CEO + ∠COE = 90° … (১)
সমকোণী △DBO-তে
∠DBO + ∠BDO = 90°
যেহেতু ∠BDO=90°, তাই সমকোণী △DBO-এর বাকি দুই কোণের সমষ্টি 90°; অর্থাৎ
∠DBO + ∠DOB = 90° … (২)
C,O,B একই সরলরেখায় এবং E,O,D একই সরলরেখায় অবস্থিত। তাই ∠COE ও ∠DOB বিপ্রতীপ কোণ; ফলে ∠COE = ∠DOB।
(১) ও (২)-এ সমান কোণ বাদ দিলে,
∠CEO = ∠DBO
অতএব, ∠CEO = ∠DBO। প্রমাণিত।
