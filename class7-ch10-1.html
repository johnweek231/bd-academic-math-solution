প্রমাণ:

 

ধরি, △ABC একটি সমবাহু ত্রিভুজ।

 
AB = BC = CA
 

যেহেতু AB = AC, তাই সমদ্বিবাহু ত্রিভুজের উপপাদ্য অনুসারে,

 
∠B = ∠C
 

আবার BC = CA, তাই

 
∠A = ∠B
 

সুতরাং,

 
∠A = ∠B = ∠C
 

ত্রিভুজের তিন কোণের সমষ্টি ১৮০°।

 
∠A + ∠B + ∠C = 180°
 

তিনটি কোণ সমান হলে,

 
3∠A = 180°
∠A = 60°
 

অতএব,

 
∠A = ∠B = ∠C = 60°
 
সমবাহু ত্রিভুজের সকল কোণ পরস্পর সমান। (প্রমাণিত)
