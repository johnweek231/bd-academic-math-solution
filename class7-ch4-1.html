★প্রয়োজনীয় সূত্র ও নিয়ম

১। সূচকের নিয়ম: am × an = am+n

২। চিহ্নের নিয়ম: (+) × (+) = (+), (−) × (−) = (+), (+) × (−) = (−)

৩। বণ্টন নিয়ম: a(b + c) = ab + ac

৪। বহুপদী × বহুপদী: (a + b)(c + d) = a(c + d) + b(c + d) = ac + ad + bc + bd

৫। সদৃশ পদগুলো একত্র করে সরল করতে হয়।

১১ম রাশি: 3ab, ২য় রাশি: 4a3 — গুণফল নির্ণয় করো।

সমাধান:

গুণফল = (3ab) × (4a3)

= (3 × 4) × (a × a3) × b

= 12 × a1+3 × b

= 12a4b

উত্তর: 12a4b

২১ম রাশি: 5xy, ২য় রাশি: 6az — গুণফল নির্ণয় করো।

সমাধান:

গুণফল = (5xy) × (6az)

= (5 × 6) × a × x × y × z

= 30 × axyz

= 30axyz

উত্তর: 30axyz

৩১ম রাশি: 5a2x2, ২য় রাশি: 3ax5y — গুণফল নির্ণয় করো।

সমাধান:

গুণফল = (5a2x2) × (3ax5y)

= (5 × 3) × (a2 × a) × (x2 × x5) × y

= 15 × a2+1 × x2+5 × y

= 15a3x7y

উত্তর: 15a3x7y

৪১ম রাশি: 8a2b, ২য় রাশি: −2b2 — গুণফল নির্ণয় করো।

সমাধান:

গুণফল = (8a2b) × (−2b2)

= {8 × (−2)} × a2 × (b × b2)

= −16 × a2 × b1+2

= −16a2b3

উত্তর: −16a2b3

৫১ম রাশি: −2abx2, ২য় রাশি: 10b3xyz — গুণফল নির্ণয় করো।

সমাধান:

গুণফল = (−2abx2) × (10b3xyz)

= {(−2) × 10} × a × (b × b3) × (x2 × x) × y × z

= −20 × a × b1+3 × x2+1 × yz

= −20ab4x3yz

উত্তর: −20ab4x3yz

৬১ম রাশি: −3p2q3, ২য় রাশি: −6p5q4 — গুণফল নির্ণয় করো।

সমাধান:

গুণফল = (−3p2q3) × (−6p5q4)

= {(−3) × (−6)} × (p2 × p5) × (q3 × q4)

= +18 × p2+5 × q3+4

= 18p7q7

উত্তর: 18p7q7

৭১ম রাশি: −12m2a2x3, ২য় রাশি: −2ma2x2 — গুণফল নির্ণয় করো।

সমাধান:

গুণফল = (−12m2a2x3) × (−2ma2x2)

= {(−12) × (−2)} × (m2 × m) × (a2 × a2) × (x3 × x2)

= +24 × m2+1 × a2+2 × x3+2

= 24m3a4x5

উত্তর: 24m3a4x5

৮১ম রাশি: 7a3bx5y2, ২য় রাশি: −3x5y3a2b2 — গুণফল নির্ণয় করো।

সমাধান:

গুণফল = (7a3bx5y2) × (−3x5y3a2b2)

= {7 × (−3)} × (a3 × a2) × (b × b2) × (x5 × x5) × (y2 × y3)

= −21 × a3+2 × b1+2 × x5+5 × y2+3

= −21a5b3x10y5

উত্তর: −21a5b3x10y5

৯১ম রাশি: 2x+3y, ২য় রাশি: 5xy — গুণফল নির্ণয় করো।

সমাধান:

গুণফল = (2x+3y) × (5xy)

= 2x × 5xy + 3y × 5xy [বণ্টন নিয়ম]

= (2 × 5) × (x × x) × y + (3 × 5) × x × (y × y)

= 10x1+1y + 15xy1+1

= 10x2y + 15xy2

উত্তর: 10x2y + 15xy2

১০১ম রাশি: 5x2−4xy, ২য় রাশি: 9x2y2 — গুণফল নির্ণয় করো।

সমাধান:

গুণফল = (5x2−4xy) × (9x2y2)

= 5x2 × 9x2y2 − 4xy × 9x2y2

= (5 × 9) × (x2 × x2) × y2 − (4 × 9) × (x × x2) × (y × y2)

= 45x2+2y2 − 36x1+2y1+2

= 45x4y2 − 36x3y3

উত্তর: 45x4y2 − 36x3y3

১১১ম রাশি: 2a2−3b2+c2, ২য় রাশি: a3b2 — গুণফল নির্ণয় করো।

সমাধান:

গুণফল = (2a2−3b2+c2) × (a3b2)

= 2a2 × a3b2 − 3b2 × a3b2 + c2 × a3b2

= 2 × (a2 × a3) × b2 − 3 × a3 × (b2 × b2) + a3b2c2

= 2a2+3b2 − 3a3b2+2 + a3b2c2

= 2a5b2 − 3a3b4 + a3b2c2

উত্তর: 2a5b2 − 3a3b4 + a3b2c2

১২১ম রাশি: x3−y3+3xyz, ২য় রাশি: x4y — গুণফল নির্ণয় করো।

সমাধান:

গুণফল = (x3−y3+3xyz) × (x4y)

= x3 × x4y − y3 × x4y + 3xyz × x4y

= (x3 × x4) × y − x4 × (y3 × y) + 3 × (x × x4) × (y × y) × z

= x3+4y − x4y3+1 + 3x1+4y1+1z

= x7y − x4y4 + 3x5y2z

উত্তর: x7y − x4y4 + 3x5y2z

১৩১ম রাশি: 2a−3b, ২য় রাশি: 3a+2b — গুণফল নির্ণয় করো।

সমাধান:

গুণফল = (2a−3b) × (3a+2b)

= 2a(3a+2b) − 3b(3a+2b)

= 6a2 + 4ab − 9ab − 6b2

= 6a2 + (4ab − 9ab) − 6b2

= 6a2 − 5ab − 6b2

উত্তর: 6a2 − 5ab − 6b2

১৪১ম রাশি: a+b, ২য় রাশি: a−b — গুণফল নির্ণয় করো।

সমাধান:

গুণফল = (a+b) × (a−b)

= a(a−b) + b(a−b)

= a2 − ab + ab − b2

= a2 − b2

উত্তর: a2 − b2

১৫১ম রাশি: x2+1, ২য় রাশি: x2−1 — গুণফল নির্ণয় করো।

সমাধান:

গুণফল = (x2+1) × (x2−1)

= x2(x2−1) + 1(x2−1)

= x2+2 − x2 + x2 − 1

= x4 − 1

উত্তর: x4 − 1

১৬১ম রাশি: a2+b2, ২য় রাশি: a+b — গুণফল নির্ণয় করো।

সমাধান:

গুণফল = (a2+b2) × (a+b)

= a2(a+b) + b2(a+b)

= a3 + a2b + ab2 + b3

= a3 + a2b + ab2 + b3

উত্তর: a3 + a2b + ab2 + b3

১৭১ম রাশি: a2−ab+b2, ২য় রাশি: a+b — গুণফল নির্ণয় করো।

সমাধান:

গুণফল = (a2−ab+b2) × (a+b)

= a2(a+b) − ab(a+b) + b2(a+b)

= a3 + a2b − a2b − ab2 + ab2 + b3

= a3 + (a2b − a2b) + (−ab2 + ab2) + b3

= a3 + b3

উত্তর: a3 + b3

১৮১ম রাশি: x2+2xy+y2, ২য় রাশি: x+y — গুণফল নির্ণয় করো।

সমাধান:

গুণফল = (x2+2xy+y2) × (x+y)

= x2(x+y) + 2xy(x+y) + y2(x+y)

= x3 + x2y + 2x2y + 2xy2 + xy2 + y3

= x3 + (x2y + 2x2y) + (2xy2 + xy2) + y3

= x3 + 3x2y + 3xy2 + y3

উত্তর: x3 + 3x2y + 3xy2 + y3

১৯১ম রাশি: x2−2xy+y2, ২য় রাশি: x−y — গুণফল নির্ণয় করো।

সমাধান:

গুণফল = (x2−2xy+y2) × (x−y)

= x2(x−y) − 2xy(x−y) + y2(x−y)

= x3 − x2y − 2x2y + 2xy2 + xy2 − y3

= x3 − (x2y + 2x2y) + (2xy2 + xy2) − y3

= x3 − 3x2y + 3xy2 − y3

উত্তর: x3 − 3x2y + 3xy2 − y3

২০১ম রাশি: x2+2x−3, ২য় রাশি: x+3 — গুণফল নির্ণয় করো।

সমাধান:

গুণফল = (x2+2x−3) × (x+3)

= x2(x+3) + 2x(x+3) − 3(x+3)

= x3 + 3x2 + 2x2 + 6x − 3x − 9

= x3 + (3x2 + 2x2) + (6x − 3x) − 9

= x3 + 5x2 + 3x − 9

উত্তর: x3 + 5x2 + 3x − 9

২১১ম রাশি: a2+ab+b2, ২য় রাশি: b2−ab+a2 — গুণফল নির্ণয় করো।

সমাধান:

গুণফল = (a2+ab+b2) × (b2−ab+a2)

২য় রাশিকে a-এর ঘাতের অবরোহী ক্রমে সাজিয়ে পাই: b2 − ab + a2 = a2 − ab + b2

∴ গুণফল = (a2+ab+b2)(a2−ab+b2)

= a2(a2−ab+b2) + ab(a2−ab+b2) + b2(a2−ab+b2)

= a4 − a3b + a2b2 + a3b − a2b2 + ab3 + a2b2 − ab3 + b4

= a4 + (−a3b + a3b) + (a2b2 − a2b2 + a2b2) + (ab3 − ab3) + b4

= a4 + a2b2 + b4

উত্তর: a4 + a2b2 + b4

২২১ম রাশি: a+b+c, ২য় রাশি: a+b+c — গুণফল নির্ণয় করো।

সমাধান:

গুণফল = (a+b+c) × (a+b+c)

= a(a+b+c) + b(a+b+c) + c(a+b+c)

= a2 + ab + ac + ab + b2 + bc + ac + bc + c2

= a2 + b2 + c2 + (ab + ab) + (bc + bc) + (ac + ac)

= a2 + b2 + c2 + 2ab + 2bc + 2ca

উত্তর: a2 + b2 + c2 + 2ab + 2bc + 2ca

২৩১ম রাশি: x2+xy+y2, ২য় রাশি: x2−xy+y2 — গুণফল নির্ণয় করো।

সমাধান:

গুণফল = (x2+xy+y2) × (x2−xy+y2)

= x2(x2−xy+y2) + xy(x2−xy+y2) + y2(x2−xy+y2)

= x4 − x3y + x2y2 + x3y − x2y2 + xy3 + x2y2 − xy3 + y4

= x4 + (−x3y + x3y) + (x2y2 − x2y2 + x2y2) + (xy3 − xy3) + y4

= x4 + x2y2 + y4

উত্তর: x4 + x2y2 + y4

২৪১ম রাশি: y2−y+1, ২য় রাশি: 1+y+y2 — গুণফল নির্ণয় করো।

সমাধান:

গুণফল = (y2−y+1) × (1+y+y2)

২য় রাশিকে y-এর ঘাতের অবরোহী ক্রমে সাজিয়ে পাই: 1 + y + y2 = y2 + y + 1

∴ গুণফল = (y2−y+1)(y2+y+1)

= y2(y2+y+1) − y(y2+y+1) + 1(y2+y+1)

= y4 + y3 + y2 − y3 − y2 − y + y2 + y + 1

= y4 + (y3 − y3) + (y2 − y2 + y2) + (−y + y) + 1

= y4 + y2 + 1

উত্তর: y4 + y2 + 1

২৫A = x2 + xy + y2 এবং B = x − y হলে, প্রমাণ করো যে, AB = x3 − y3

দেওয়া আছে: A = x2 + xy + y2 এবং B = x − y

প্রমাণ করতে হবে: AB = x3 − y3

প্রমাণ:

AB = (x2 + xy + y2)(x − y)

= x2(x−y) + xy(x−y) + y2(x−y)

= x3 − x2y + x2y − xy2 + xy2 − y3

= x3 + (−x2y + x2y) + (−xy2 + xy2) − y3

= x3 − y3

∴ AB = x3 − y3 (প্রমাণিত)

উত্তর: AB = x3 − y3 (প্রমাণিত)

২৬A = a2 − ab + b2 এবং B = a + b হলে, AB = কত?

সমাধান:

AB = (a2 − ab + b2)(a + b)

= a2(a+b) − ab(a+b) + b2(a+b)

= a3 + a2b − a2b − ab2 + ab2 + b3

= a3 + (a2b − a2b) + (−ab2 + ab2) + b3

= a3 + b3

উত্তর: AB = a3 + b3

২৭দেখাও যে, (a+1)(a−1)(a2+1) = a4 − 1

সমাধান:

বামপক্ষ = (a+1)(a−1)(a2+1)

= {(a+1)(a−1)}(a2+1) [প্রথম দুটি উৎপাদক আগে গুণ করে]

(a+1)(a−1) = a(a−1) + 1(a−1) = a2 − a + a − 1 = a2 − 1

∴ বামপক্ষ = (a2 − 1)(a2 + 1)

= a2(a2+1) − 1(a2+1)

= a4 + a2 − a2 − 1

= a4 − 1 = ডানপক্ষ

∴ (a+1)(a−1)(a2+1) = a4 − 1 (দেখানো হলো)

উত্তর: (a+1)(a−1)(a2+1) = a4 − 1 (দেখানো হলো)

২৮দেখাও যে, (x+y)(x−y)(x2+y2) = x4 − y4

সমাধান:

বামপক্ষ = (x+y)(x−y)(x2+y2)

= {(x+y)(x−y)}(x2+y2)

(x+y)(x−y) = x(x−y) + y(x−y) = x2 − xy + xy − y2 = x2 − y2

∴ বামপক্ষ = (x2 − y2)(x2 + y2)

= x2(x2+y2) − y2(x2+y2)

= x4 + x2y2 − x2y2 − y4

= x4 − y4 = ডানপক্ষ

∴ (x+y)(x−y)(x2+y2) = x4 − y4 (দেখানো হলো)

উত্তর: (x+y)(x−y)(x2+y2) = x4 − y4 (দেখানো হলো)
