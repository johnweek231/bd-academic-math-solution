গণিত – পৃষ্ঠা ৭৮ | সূত্রের সাহায্যে গুণফল নির্ণয়

সূত্রের সাহায্যে গুণফল নির্ণয় করো (১–১২)

সূত্র: (a + b)(a − b) = a² − b²  |  (x + a)(x + b) = x² + (a + b)x + ab  |  (a + b)² = a² + 2ab + b²

১ (4x + 3), (4x − 3)

সমাধান: (4x + 3)(4x − 3)
= (4x)² − 3²  [(a+b)(a−b) = a² − b²]
= 16x² − 9
উত্তর: 16x² − 9

২ (13 − 12p), (13 + 12p)

সমাধান: (13 − 12p)(13 + 12p)
= 13² − (12p)²
= 169 − 144p²
উত্তর: 169 − 144p²

৩ (ab + 3), (ab − 3)

সমাধান: (ab + 3)(ab − 3)
= (ab)² − 3²
= a²b² − 9
উত্তর: a²b² − 9

৪ (10 − xy), (10 + xy)

সমাধান: (10 − xy)(10 + xy)
= 10² − (xy)²
= 100 − x²y²
উত্তর: 100 − x²y²

৫ (4x² + 3y²), (4x² − 3y²)

সমাধান: (4x² + 3y²)(4x² − 3y²)
= (4x²)² − (3y²)²
= 16x⁴ − 9y⁴
উত্তর: 16x⁴ − 9y⁴

৬ (a − b − c), (a + b + c)

সমাধান: (a − b − c)(a + b + c)
= {a − (b + c)}{a + (b + c)}  [b ও c কে একত্রে (b + c) ধরে]
= a² − (b + c)²  [(x−y)(x+y) = x² − y²]
= a² − (b² + 2bc + c²)  [(b+c)² সূত্র]
= a² − b² − 2bc − c²
উত্তর: a² − b² − c² − 2bc

৭ (x² − x + 1), (x² + x + 1)

সমাধান: (x² − x + 1)(x² + x + 1)
= {(x² + 1) − x}{(x² + 1) + x}  [(x² + 1) কে একত্রে ধরে]
= (x² + 1)² − x²  [(a−b)(a+b) = a² − b²]
= (x²)² + 2·x²·1 + 1² − x²
= x⁴ + 2x² + 1 − x²
= x⁴ + x² + 1
উত্তর: x⁴ + x² + 1

৮ (x − 12a), (x − 52a)

সমাধান: (x − a/2)(x − 5a/2)
= {x + (−a/2)}{x + (−5a/2)}
= x² + {(−a/2) + (−5a/2)}x + (−a/2)(−5a/2)  [(x+p)(x+q) = x² + (p+q)x + pq]
= x² + (−6a/2)x + 5a²/4
= x² − 3ax + 5a²/4
উত্তর: x² − 3ax + 5a²4

৯ (14x − 13y), (14x + 13y)

সমাধান: (x/4 − y/3)(x/4 + y/3)
= (x/4)² − (y/3)²  [(a−b)(a+b) = a² − b²]
= x²/16 − y²/9
উত্তর: x²16 − y²9

১০ (a⁴ + 3a²x² + 9x⁴), (9x⁴ − 3a²x² + a⁴)

সমাধান: (a⁴ + 3a²x² + 9x⁴)(a⁴ − 3a²x² + 9x⁴)
= {(a⁴ + 9x⁴) + 3a²x²}{(a⁴ + 9x⁴) − 3a²x²}  [(a⁴ + 9x⁴) কে একত্রে ধরে]
= (a⁴ + 9x⁴)² − (3a²x²)²  [(p+q)(p−q) = p² − q²]
= (a⁴)² + 2·a⁴·9x⁴ + (9x⁴)² − 9a⁴x⁴
= a⁸ + 18a⁴x⁴ + 81x⁸ − 9a⁴x⁴
= a⁸ + 9a⁴x⁴ + 81x⁸
উত্তর: a⁸ + 9a⁴x⁴ + 81x⁸

১১ (x + 1), (x − 1), (x² + 1)

সমাধান: (x + 1)(x − 1)(x² + 1)
= (x² − 1²)(x² + 1)  [(x+1)(x−1) = x² − 1]
= (x² − 1)(x² + 1)
= (x²)² − 1²  [(a−b)(a+b) = a² − b²]
= x⁴ − 1
উত্তর: x⁴ − 1

১২ (9a² + b²), (3a + b), (3a − b)

সমাধান: (9a² + b²)(3a + b)(3a − b)
= (9a² + b²){(3a)² − b²}  [(3a+b)(3a−b) = (3a)² − b²]
= (9a² + b²)(9a² − b²)
= (9a²)² − (b²)²  [(p+q)(p−q) = p² − q²]
= 81a⁴ − b⁴
উত্তর: 81a⁴ − b⁴
