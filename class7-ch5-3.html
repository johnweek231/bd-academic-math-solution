NCTB গণিত · অধ্যায় ৫

অনুশীলনী ৫.৩ — বীজগণিতীয় উৎপাদকে বিশ্লেষণ

প্রতিটি রাশিকে সূত্র ও সাধারণ উৎপাদক ব্যবহার করে ধাপে ধাপে উৎপাদকে বিশ্লেষণ করা হয়েছে।

মনে রাখবে: সাধারণ উৎপাদক বের করা, পদগুলোকে দলবদ্ধ করা এবং বর্গের অন্তর সূত্র প্রয়োগ করাই এই অনুশীলনীর প্রধান কৌশল।

১x2 + xy + xz + yz

দলবদ্ধ করে উৎপাদক বিশ্লেষণ

প্রথম দুটি পদ এবং শেষ দুটি পদ একসঙ্গে লিখি।

= x(x + y) + z(x + y)

উভয় পদের সাধারণ উৎপাদক (x + y)।

= (x + y)(x + z)

উত্তর: (x + y)(x + z)

২a2 + bc + ca + ab

পদগুলো দলবদ্ধ করি

= a2 + ab + ac + bc = a(a + b) + c(a + b)

এখানে (a + b) সাধারণ উৎপাদক।

= (a + b)(a + c)

উত্তর: (a + b)(a + c)

৩ab(px + qy) + a2qx + b2py

প্রথমে বন্ধনী খুলে পদগুলো দলবদ্ধ করি

= abpx + abqy + a2qx + b2py = (abpx + a2qx) + (b2py + abqy) = ax(bp + aq) + by(bp + aq)

এখন (bp + aq) সাধারণ উৎপাদক।

= (ax + by)(bp + aq)

উত্তর: (ax + by)(bp + aq)

৪4x2 − y2

বর্গের অন্তর সূত্র

সূত্র: A2 − B2 = (A − B)(A + B)। এখানে A = 2x এবং B = y।

= (2x)2 − y2 = (2x − y)(2x + y)

উত্তর: (2x − y)(2x + y)

৫9a2 − 4b2

বর্গের অন্তর সূত্র

= (3a)2 − (2b)2 = (3a − 2b)(3a + 2b)

উত্তর: (3a − 2b)(3a + 2b)

৬a2b2 − 49y2

বর্গের অন্তর সূত্র

= (ab)2 − (7y)2 = (ab − 7y)(ab + 7y)

উত্তর: (ab − 7y)(ab + 7y)

৭16x4 − 81y4

পরপর বর্গের অন্তর সূত্র প্রয়োগ

= (4x2)2 − (9y2)2 = (4x2 − 9y2)(4x2 + 9y2)

প্রথম বন্ধনীর রাশিটিও বর্গের অন্তর।

= (2x − 3y)(2x + 3y)(4x2 + 9y2)

উত্তর: (2x − 3y)(2x + 3y)(4x2 + 9y2)

৮a2 − (x + y)2

বর্গের অন্তর সূত্র

= a2 − (x + y)2 = [a − (x + y)][a + (x + y)]

বন্ধনী খুললে পাওয়া যায়—

= (a − x − y)(a + x + y)

উত্তর: (a − x − y)(a + x + y)

৯(2x − 3y + 5z)2 − (x − 2y + 3z)2

বর্গের অন্তর সূত্র

ধরি, A = 2x − 3y + 5z এবং B = x − 2y + 3z। তাহলে A2 − B2 = (A − B)(A + B)।

A − B = 2x − 3y + 5z − (x − 2y + 3z) = 2x − 3y + 5z − x + 2y − 3z = x − y + 2z A + B = 2x − 3y + 5z + x − 2y + 3z = 3x − 5y + 8z সুতরাং, = (x − y + 2z)(3x − 5y + 8z)

উত্তর: (x − y + 2z)(3x − 5y + 8z)

১০4 + 8a2 + 9a4

পূর্ণবর্গ তৈরি করে বর্গের অন্তর সূত্র

= 9a4 + 8a2 + 4

মাঝের পদকে 12a2 − 4a2 হিসেবে লিখি, যাতে পূর্ণবর্গ পাওয়া যায়।

= 9a4 + 12a2 + 4 − 4a2 = (3a2 + 2)2 − (2a)2 = (3a2 + 2 − 2a)(3a2 + 2 + 2a)

পদগুলো সাজিয়ে লিখলে—

= (3a2 − 2a + 2)(3a2 + 2a + 2)

উত্তর: (3a2 − 2a + 2)(3a2 + 2a + 2)

১১2a2 + 6a − 80

সাধারণ উৎপাদক বের করে ত্রিপদী বিশ্লেষণ

= 2(a2 + 3a − 40)

এমন দুটি সংখ্যা চাই, যাদের গুণফল −40 এবং যোগফল 3। সংখ্যা দুটি 8 ও −5।

= 2(a2 + 8a − 5a − 40) = 2[a(a + 8) − 5(a + 8)] = 2(a + 8)(a − 5)

উত্তর: 2(a + 8)(a − 5)

১২y2 − 6y − 91

মধ্যপদ ভেঙে উৎপাদক বিশ্লেষণ

এমন দুটি সংখ্যা চাই, যাদের গুণফল −91 এবং যোগফল −6। সংখ্যা দুটি −13 ও 7।

= y2 − 13y + 7y − 91 = y(y − 13) + 7(y − 13) = (y − 13)(y + 7)

উত্তর: (y − 13)(y + 7)

১৩p2 − 15p + 56

মধ্যপদ ভেঙে উৎপাদক বিশ্লেষণ

এমন দুটি সংখ্যা চাই, যাদের গুণফল 56 এবং যোগফল −15। সংখ্যা দুটি −7 ও −8।

= p2 − 7p − 8p + 56 = p(p − 7) − 8(p − 7) = (p − 7)(p − 8)

উত্তর: (p − 7)(p − 8)

১৪45a8 − 5a4x4

সাধারণ উৎপাদক ও বর্গের অন্তর সূত্র

= 5a4(9a4 − x4)

বন্ধনীর ভেতরের রাশি বর্গের অন্তর।

= 5a4[(3a2)2 − (x2)2] = 5a4(3a2 − x2)(3a2 + x2)

উত্তর: 5a4(3a2 − x2)(3a2 + x2)

১৫a2 + 3a − 40

মধ্যপদ ভেঙে উৎপাদক বিশ্লেষণ

এমন দুটি সংখ্যা চাই, যাদের গুণফল −40 এবং যোগফল 3। সংখ্যা দুটি 8 ও −5।

= a2 + 8a − 5a − 40 = a(a + 8) − 5(a + 8) = (a + 8)(a − 5)

উত্তর: (a + 8)(a − 5)

১৬(x2 + 1)2 − (y2 + 1)2

বর্গের অন্তর সূত্র

= [(x2 + 1) − (y2 + 1)] [(x2 + 1) + (y2 + 1)] = (x2 − y2)(x2 + y2 + 2)

এখন x2 − y2 = (x − y)(x + y)।

= (x − y)(x + y)(x2 + y2 + 2)

উত্তর: (x − y)(x + y)(x2 + y2 + 2)

১৭x2 + 11x + 30

মধ্যপদ ভেঙে উৎপাদক বিশ্লেষণ

এমন দুটি সংখ্যা চাই, যাদের গুণফল 30 এবং যোগফল 11। সংখ্যা দুটি 5 ও 6।

= x2 + 5x + 6x + 30 = x(x + 5) + 6(x + 5) = (x + 5)(x + 6)

উত্তর: (x + 5)(x + 6)

১৮a2 − b2 + 2bc − c2

পূর্ণবর্গ ও বর্গের অন্তর সূত্র

= a2 − (b2 − 2bc + c2)

যেহেতু b2 − 2bc + c2 = (b − c)2, তাই—

= a2 − (b − c)2 = [a − (b − c)][a + (b − c)] = (a − b + c)(a + b − c)

উত্তর: (a − b + c)(a + b − c)

১৯144x7 − 25x3a4

সাধারণ উৎপাদক ও বর্গের অন্তর সূত্র

= x3(144x4 − 25a4) = x3[(12x2)2 − (5a2)2] = x3(12x2 − 5a2)(12x2 + 5a2)

উত্তর: x3(12x2 − 5a2)(12x2 + 5a2)

২০4x2 + 12xy + 9y2 − 16a2

পূর্ণবর্গ ও বর্গের অন্তর সূত্র

প্রথম তিনটি পদ একটি পূর্ণবর্গ: 4x2 + 12xy + 9y2 = (2x + 3y)2। তাই—

= (2x + 3y)2 − (4a)2 = (2x + 3y − 4a)(2x + 3y + 4a)

উত্তর: (2x + 3y − 4a)(2x + 3y + 4a)
