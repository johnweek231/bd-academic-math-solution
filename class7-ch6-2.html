★প্রয়োজনীয় সূত্র ও নিয়ম

১। সমহরবিশিষ্ট ভগ্নাংশ: ac ± bc = a ± bc

২। ভিন্ন হর হলে হরগুলোর ল.সা.গু বের করে প্রতিটি ভগ্নাংশকে ল.সা.গু হরবিশিষ্ট ভগ্নাংশে রূপান্তর করতে হয়।

৩। সমতুল ভগ্নাংশ: ab = a × cb × c (c ≠ 0)

৪। a2 − b2 = (a + b)(a − b)

৫। x2 + (p + q)x + pq = (x + p)(x + q)

৬। লঘিষ্ঠ আকারে প্রকাশ করতে লব ও হরকে উৎপাদকে বিশ্লেষণ করে সাধারণ উৎপাদক কেটে দিতে হয়।

১23a ও 35ab এর সমহরবিশিষ্ট ভগ্নাংশ নিচের কোনটি?

(ক) 10b15ab, 915ab(খ) 615ab, b15ab(গ) 215a2b, 315a2b(ঘ) 10a15a2b, 9a15a2b

সমাধান:

হর দুটি 3a ও 5ab। 3 ও 5 এর ল.সা.গু = 15 এবং a ও ab এর ল.সা.গু = ab। ∴ ল.সা.গু = 15ab

15ab ÷ 3a = 5b এবং 15ab ÷ 5ab = 3

23a = 2 × 5b3a × 5b = 10b15ab

35ab = 3 × 35ab × 3 = 915ab

উত্তর: (ক) 10b15ab, 915ab

২xyz ও yzx এর সাধারণ হরবিশিষ্ট ভগ্নাংশ নিচের কোনটি?

(ক) zx2xyz2, y2zxyz2(খ) x2xyz2, y2xyz2(গ) xxyz, yxyz(ঘ) x2xyz, y2xyz

সমাধান:

হর দুটি yz ও zx। ল.সা.গু = xyz

xyz ÷ yz = x এবং xyz ÷ zx = y

xyz = x × xyz × x = x2xyz

yzx = y × yzx × y = y2xyz

(দ্রষ্টব্য: (ক)-এর ভগ্নাংশ দুটিও সমতুল্য, কিন্তু তার হর xyz2 — ল.সা.গু নয়। পাঠ্যবইয়ের নিয়মে ল.সা.গু হর নিতে হয়।)

উত্তর: (ঘ) x2xyz, y2xyz

কোনো ভগ্নাংশের লব ও হরকে একই অশূন্য রাশি দ্বারা গুণ করলে সমতুল ভগ্নাংশ পাওয়া যায়।

লব ও হরকে c দ্বারা গুণ করে পাই: ab = a × cb × c = acbc (c ≠ 0)

৫4a2b − 9b34a2b + 6ab2 এর লঘিষ্ঠ রূপ নিচের কোনটি?

(ক) 2a+3b2ab(খ) 2a−3b2ab(গ) 2a−3b2a(ঘ) 2a+3b2a

= 2a−3b2a

৬ax + bx − cx এর মান কত?

(ক) a+b+cx(খ) a+b−cx(গ) a−b−cx(ঘ) a−b+cx

3a5 + 2b5 = 3a + 2b5

৮যোগফল নির্ণয় করো: 15x + 25x

সমাধান:

15x + 25x = 1 + 25x

= 35x

উত্তর: 35x

৯যোগফল নির্ণয় করো: x2a + y3b

সমাধান:

হর দুটি 2a ও 3b। ল.সা.গু = 6ab

x2a = x × 3b2a × 3b = 3bx6ab

y3b = y × 2a3b × 2a = 2ay6ab

∴ যোগফল = 3bx6ab + 2ay6ab = 3bx + 2ay6ab

উত্তর: 3bx+2ay6ab

১০যোগফল নির্ণয় করো: 2ax+1 + 2ax−2

সমাধান:

হর দুটি (x+1) ও (x−2)। ল.সা.গু = (x+1)(x−2)

= 2a(x−2) + 2a(x+1)(x+1)(x−2)

= 2ax − 4a + 2ax + 2a(x+1)(x−2)

= 4ax − 2a(x+1)(x−2)

= 2a(2x−1)(x+1)(x−2)

উত্তর: 2a(2x−1)(x+1)(x−2)

১১যোগফল নির্ণয় করো: aa+2 + 2a−2

সমাধান:

হর দুটি (a+2) ও (a−2)। ল.সা.গু = (a+2)(a−2) = a2 − 4

= a(a−2) + 2(a+2)(a+2)(a−2)

= a2 − 2a + 2a + 4a2 − 4

= a2 + 4a2 − 4

উত্তর: a2+4a2−4

১২যোগফল নির্ণয় করো: 3x2−4x−5 + 4x+1

সমাধান:

প্রথম হর: x2 − 4x − 5 = x2 − 5x + x − 5 = x(x − 5) + 1(x − 5) = (x − 5)(x + 1)

হর দুটি (x−5)(x+1) ও (x+1)। ল.সা.গু = (x−5)(x+1)

= 3(x−5)(x+1) + 4(x−5)(x+1)(x−5)

= 3 + 4(x−5)(x−5)(x+1)

= 3 + 4x − 20(x−5)(x+1)

= 4x − 17(x−5)(x+1)

উত্তর: 4x−17(x−5)(x+1)

বিয়োগফল নির্ণয় করো (১৩–১৮)

১৩বিয়োগফল নির্ণয় করো: 2a7 − 4b7

সমাধান:

2a7 − 4b7 = 2a − 4b7

= 2(a − 2b)7

উত্তর: 2(a−2b)7

১৪বিয়োগফল নির্ণয় করো: 2x5a − 4y5a

সমাধান:

2x5a − 4y5a = 2x − 4y5a

= 2(x − 2y)5a

উত্তর: 2(x−2y)5a

১৫বিয়োগফল নির্ণয় করো: a8x − b4y

সমাধান:

হর দুটি 8x ও 4y। ল.সা.গু = 8xy

a8x = a × y8x × y = ay8xy

b4y = b × 2x4y × 2x = 2bx8xy

∴ বিয়োগফল = ay8xy − 2bx8xy = ay − 2bx8xy

উত্তর: ay−2bx8xy

১৬বিয়োগফল নির্ণয় করো: 3x+3 − 2x+2

সমাধান:

ল.সা.গু = (x+3)(x+2)

= 3(x+2) − 2(x+3)(x+3)(x+2)

= 3x + 6 − 2x − 6(x+3)(x+2)

= x(x+3)(x+2)

উত্তর: x(x+3)(x+2)

১৭বিয়োগফল নির্ণয় করো: p+qpq − q+rqr

সমাধান:

হর দুটি pq ও qr। ল.সা.গু = pqr

p+qpq = r(p+q)pqr এবং q+rqr = p(q+r)pqr

∴ বিয়োগফল = r(p+q) − p(q+r)pqr

= pr + qr − pq − prpqr

= qr − pqpqr = q(r−p)pqr

= r − ppr [লব ও হর থেকে q কেটে]

উত্তর: r−ppr

১৮বিয়োগফল নির্ণয় করো: 2xx2−4y2 − xxy+2y2

সমাধান:

x2 − 4y2 = x2 − (2y)2 = (x + 2y)(x − 2y)

xy + 2y2 = y(x + 2y)

হর দুটির ল.সা.গু = y(x+2y)(x−2y)

2x(x+2y)(x−2y) = 2x × yy(x+2y)(x−2y) = 2xyy(x+2y)(x−2y)

xy(x+2y) = x(x−2y)y(x+2y)(x−2y)

∴ বিয়োগফল = 2xy − x(x−2y)y(x+2y)(x−2y)

= 2xy − x2 + 2xyy(x+2y)(x−2y)

= 4xy − x2y(x+2y)(x−2y)

= x(4y − x)y(x+2y)(x−2y)

উত্তর: x(4y−x)y(x+2y)(x−2y)

সরল করো (১৯–২৪)

১৯সরল করো: 5a2−6a+5 + 1a−1

সমাধান:

a2 − 6a + 5 = a2 − 5a − a + 5 = a(a − 5) − 1(a − 5) = (a − 5)(a − 1)

ল.সা.গু = (a−5)(a−1)

= 5(a−5)(a−1) + 1 × (a−5)(a−1)(a−5)

= 5 + a − 5(a−5)(a−1)

= a(a−5)(a−1)

উত্তর: a(a−1)(a−5)

২০সরল করো: 1x+2 − 1x2−4

সমাধান:

x2 − 4 = (x + 2)(x − 2)

ল.সা.গু = (x+2)(x−2)

= 1 × (x−2)(x+2)(x−2) − 1(x+2)(x−2)

= x − 2 − 1(x+2)(x−2)

= x − 3x2 − 4

উত্তর: x−3x2−4

২১সরল করো: a3 + a6 − 3a8

সমাধান:

হর 3, 6, 8 এর ল.সা.গু = 24

a3 = 8a24, a6 = 4a24, 3a8 = 9a24

= 8a + 4a − 9a24

= 3a24

= a8

উত্তর: a8

২২সরল করো: ab − 3a2b + 2a3b

সমাধান:

হর b, 2b, 3b এর ল.সা.গু = 6b

ab = 6a6b, 3a2b = 9a6b, 2a3b = 4a6b

= 6a − 9a + 4a6b

= a6b

উত্তর: a6b

২৩সরল করো: xyz − yzx + zxy

সমাধান:

হর yz, zx, xy এর ল.সা.গু = xyz

xyz = x2xyz, yzx = y2xyz, zxy = z2xyz

= x2 − y2 + z2xyz

উত্তর: x2−y2+z2xyz

২৪সরল করো: x−yxy + y−zyz + z−xzx

সমাধান:

ল.সা.গু = xyz

x−yxy = z(x−y)xyz, y−zyz = x(y−z)xyz, z−xzx = y(z−x)xyz

= z(x−y) + x(y−z) + y(z−x)xyz

= zx − zy + xy − xz + yz − xyxyz

= (zx − xz) + (yz − zy) + (xy − xy)xyz

= 0xyz = 0

উত্তর: 0

২৫তিনটি বীজগাণিতীয় ভগ্নাংশ: xx+y, xx−4y, yx2−3xy−4y2
(ক) উৎপাদকে বিশ্লেষণ করো: a2 − 3a + 2
(খ) ১ম ও ২য় ভগ্নাংশকে সমহরবিশিষ্ট ভগ্নাংশে প্রকাশ করো।
(গ) ভগ্নাংশ তিনটির যোগফল নির্ণয় করো।

(ক) সমাধান:

a2 − 3a + 2 = a2 − 2a − a + 2 [গুণফল 2 ও যোগফল −3 হয় এমন সংখ্যা −2 ও −1]

= a(a − 2) − 1(a − 2)

= (a − 2)(a − 1)

(খ) সমাধান:

হর দুটি (x+y) ও (x−4y)। ল.সা.গু = (x+y)(x−4y)

xx+y = x(x−4y)(x+y)(x−4y) = x2 − 4xy(x+y)(x−4y)

xx−4y = x(x+y)(x+y)(x−4y) = x2 + xy(x+y)(x−4y)

(গ) সমাধান:

x2 − 3xy − 4y2 = x2 − 4xy + xy − 4y2 = x(x − 4y) + y(x − 4y) = (x − 4y)(x + y)

∴ ৩য় ভগ্নাংশ = y(x+y)(x−4y); তিনটি হরের ল.সা.গু = (x+y)(x−4y)

যোগফল = xx+y + xx−4y + y(x+y)(x−4y)

= x(x−4y) + x(x+y) + y(x+y)(x−4y)

= x2 − 4xy + x2 + xy + y(x+y)(x−4y)

= 2x2 − 3xy + y(x+y)(x−4y)

= 2x2 − 3xy + yx2 − 3xy − 4y2

উত্তর: (ক) (a−1)(a−2) (খ) x2−4xy(x+y)(x−4y), x2+xy(x+y)(x−4y) (গ) 2x2−3xy+y(x+y)(x−4y)

২৬তিনটি বীজগাণিতীয় ভগ্নাংশ: 1a2+3a, 1a2+5a+6, 1a2−a−12
(ক) ৩য় ভগ্নাংশের হরকে উৎপাদকে বিশ্লেষণ করো।
(খ) ১ম ও ২য় ভগ্নাংশকে সমহরবিশিষ্ট ভগ্নাংশে রূপান্তর করো।
(গ) ১ম, ২য় ও ৩য় ভগ্নাংশের যোগফল নির্ণয় করো।

(ক) সমাধান:

a2 − a − 12 = a2 − 4a + 3a − 12 [গুণফল −12, যোগফল −1: −4 ও 3]

= a(a − 4) + 3(a − 4)

= (a − 4)(a + 3)

(খ) সমাধান:

a2 + 3a = a(a + 3) এবং a2 + 5a + 6 = a2 + 3a + 2a + 6 = a(a+3) + 2(a+3) = (a + 2)(a + 3)

ল.সা.গু = a(a+2)(a+3)

1a2+3a = 1a(a+3) = a+2a(a+2)(a+3)

1a2+5a+6 = 1(a+2)(a+3) = aa(a+2)(a+3)

(গ) সমাধান:

৩য় ভগ্নাংশ = 1(a−4)(a+3); তিনটি হরের ল.সা.গু = a(a+2)(a+3)(a−4)

যোগফল = 1a(a+3) + 1(a+2)(a+3) + 1(a−4)(a+3)

= (a+2)(a−4) + a(a−4) + a(a+2)a(a+2)(a+3)(a−4)

= a2 − 2a − 8 + a2 − 4a + a2 + 2aa(a+2)(a+3)(a−4)

= 3a2 − 4a − 8a(a+2)(a+3)(a−4)

উত্তর: (ক) (a−4)(a+3) (খ) a+2a(a+2)(a+3), aa(a+2)(a+3) (গ) 3a2−4a−8a(a+2)(a+3)(a−4)

নমুনা প্রশ্ন – বহুনির্বাচনি প্রশ্ন

১1a+b + 1a−b এর মান কত?

ল.সা.গু = (a+b)(a−b) = a2 − b2

= (a−b) + (a+b)(a+b)(a−b)

= a − b + a + ba2 − b2

= 2aa2 − b2

২x2xy ভগ্নাংশটির—
i. লঘিষ্ঠ আকার xy
ii. সমতুল ভগ্নাংশ x2+1xy+1
iii. সমহরবিশিষ্ট একটি ভগ্নাংশ x2+3xy
নিচের কোনটি সঠিক?

(ক) i ও ii(খ) i ও iii(গ) ii ও iii(ঘ) i, ii ও iii

সমাধান:

i. x2xy = x · xx · y = xy (লব ও হর থেকে x কেটে)। ∴ (i) সঠিক।

ii. সমতুল ভগ্নাংশ পেতে লব ও হরকে একই রাশি দ্বারা গুণ বা ভাগ করতে হয়; লব ও হরের সাথে 1 যোগ করলে মান বদলে যায়। x2+1xy+1 ≠ x2xy। ∴ (ii) সঠিক নয়।

iii. x2+3xy এর হর xy, যা x2xy এর হরের সমান। ∴ এটি সমহরবিশিষ্ট ভগ্নাংশ। ∴ (iii) সঠিক।

উত্তর: (খ) i ও iii
নিচের তথ্যের আলোকে ৩ ও ৪ নং প্রশ্নের উত্তর দাও:
x2+2x(x+2)(x−2) এবং x2+4x−4x2−4 দুটি বীজগাণিতীয় ভগ্নাংশ।

৩প্রথম ভগ্নাংশটির লঘিষ্ঠ আকার কোনটি?

(ক) xx−2(খ) xx+2(গ) x+2x−2(ঘ) x−2x+2

সমাধান:

লব = x2 + 2x = x(x + 2)

x2+2x(x+2)(x−2) = x(x+2)(x+2)(x−2)

লব ও হর থেকে (x+2) কেটে পাই, = xx−2

৪দ্বিতীয় ভগ্নাংশ থেকে প্রথম ভগ্নাংশ বিয়োগ করলে বিয়োগফল কত হবে?

(ক) 2x−2(খ) 2x+2(গ) −2x−2(ঘ) −2x+2

সমাধান:

x2 − 4 = (x+2)(x−2), তাই দুটি ভগ্নাংশেরই হর (x+2)(x−2)

বিয়োগফল = x2+4x−4x2−4 − x2+2x(x+2)(x−2)

= x2 + 4x − 4 − x2 − 2xx2 − 4

= 2x − 4x2 − 4 = 2(x−2)(x+2)(x−2)

= 2x+2

উত্তর: (খ) 2x+2

নমুনা প্রশ্ন – সৃজনশীল প্রশ্ন

৫3x2−x−12, 4x2−9, x−1x2+3x ও 3x+6x(x2+5x+6) চারটি ভগ্নাংশ।
(ক) a2−2a3(a−2) -কে লঘিষ্ঠ আকারে প্রকাশ করো।
(খ) প্রথম ও দ্বিতীয় ভগ্নাংশকে সাধারণ হরবিশিষ্ট ভগ্নাংশে প্রকাশ করো।
(গ) তৃতীয় ও চতুর্থ ভগ্নাংশের সমষ্টি নির্ণয় করো।

(ক) সমাধান:

a2−2a3(a−2) = a(a−2)3(a−2)

লব ও হর থেকে (a−2) কেটে পাই, = a3

(খ) সমাধান:

x2 − x − 12 = x2 − 4x + 3x − 12 = x(x − 4) + 3(x − 4) = (x − 4)(x + 3)

x2 − 9 = (x + 3)(x − 3)

হর দুটির ল.সা.গু = (x−4)(x+3)(x−3)

3x2−x−12 = 3(x−4)(x+3) = 3(x−3)(x−4)(x+3)(x−3) = 3x − 9(x−4)(x+3)(x−3)

4x2−9 = 4(x+3)(x−3) = 4(x−4)(x−4)(x+3)(x−3) = 4x − 16(x−4)(x+3)(x−3)

(গ) সমাধান:

x2 + 3x = x(x + 3) এবং x2 + 5x + 6 = x2 + 3x + 2x + 6 = x(x+3) + 2(x+3) = (x + 2)(x + 3)

৩য় ভগ্নাংশ = x−1x(x+3)

৪র্থ ভগ্নাংশ = 3x+6x(x+2)(x+3) = 3(x+2)x(x+2)(x+3) = 3x(x+3)

সমষ্টি = x−1x(x+3) + 3x(x+3)

= x − 1 + 3x(x+3)

= x + 2x(x+3) = x+2x2+3x

উত্তর: (ক) a3 (খ) 3x−9(x−4)(x+3)(x−3), 4x−16(x−4)(x+3)(x−3) (গ) x+2x(x+3)

নমুনা প্রশ্ন – সংক্ষিপ্ত-উত্তর প্রশ্ন

৬(ক) 1x−4 ও xx+2 ভগ্নাংশদ্বয়কে সাধারণ হরবিশিষ্ট ভগ্নাংশে প্রকাশ করো।
(খ) −axa−b থেকে bxb−a বিয়োগ করলে বিয়োগফল কত হবে তা নির্ণয় করো।
(গ) a+ba−b এর সাথে কোন ভগ্নাংশ যোগ করলে যোগফল 1 হবে তা নির্ণয় করো।

(ক) সমাধান:

হর দুটি (x−4) ও (x+2)। ল.সা.গু = (x−4)(x+2)

1x−4 = 1 × (x+2)(x−4)(x+2) = x+2(x−4)(x+2)

xx+2 = x(x−4)(x+2)(x−4) = x2 − 4x(x−4)(x+2)

(খ) সমাধান:

b − a = −(a − b), তাই bxb−a = bx−(a−b) = −bxa−b

বিয়োগফল = −axa−b − −bxa−b

= −ax + bxa−b

= −x(a−b)a−b

= −x

(গ) সমাধান:

ধরি, নির্ণেয় ভগ্নাংশ = A। শর্তমতে, a+ba−b + A = 1

⟹ A = 1 − a+ba−b

= (a−b) − (a+b)a−b

= a − b − a − ba−b

= −2ba−b = 2bb−a

উত্তর: (ক) x+2(x−4)(x+2), x2−4x(x−4)(x+2) (খ) −x (গ) −2ba−b
